# Engine does not start / battery flat
Applies to: BL-STRT, GPU-STRT, BT-BATT
Example procedure for this demo. Always follow the OEM manual and station safety rules.

## Safety
Chock the wheels and set the parking brake. Disconnect the battery negative before working on the starter circuit.

## Diagnosis
Measure battery voltage: below 12.2 V (12 V system) means charge or replace the battery (P-BATT-12V). If the battery is good and the starter only clicks or does not turn, test the starter solenoid and motor.

## Repair
Replace the battery, or replace the starter motor (P-STRT-12V for belt loaders, P-STRT-24V for GPUs). Clean and tighten terminals.

## Test before release
Start the engine three times from cold. Check charging voltage at idle. Record the failure code and part used.
