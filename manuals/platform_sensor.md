# Platform proximity sensor fault (catering high-loader)
Applies to: CHL-SENS
Example procedure for this demo. Always follow the OEM manual and station safety rules.

## Safety
A faulty proximity sensor can let the platform touch the aircraft. Take the unit out of service until repaired.

## Diagnosis
Check the sensor indicator light while moving a metal plate in front of it. Inspect the connector and cable for damage.

## Repair
Replace the platform proximity sensor (P-SENS-CHL) and set the switching distance to the OEM value.

## Test before release
Test the slow-down and stop functions against a test bumper three times. Record the failure code and part used.
