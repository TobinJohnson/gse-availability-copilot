# Ground power unit output fault
Applies to: GPU-AVR, GPU-CBL
Example procedure for this demo. Always follow the OEM manual and station safety rules.

## Safety
Never connect a GPU with an output fault to an aircraft. Isolate the unit and lock out the output contactor before opening panels.

## Diagnosis
Measure output voltage and frequency on a load bank: it must be 115/200 V, 400 Hz within limits. Out-of-limits voltage points to the voltage regulator; intermittent faults or visible damage point to the 400 Hz cable or plug.

## Repair
Replace the voltage regulator module (P-AVR-GPU) or the 400 Hz output cable (P-CBL-GPU). Check plug pins for burn marks.

## Test before release
Run 15 minutes on the load bank at rated load and record voltage and frequency. Record the failure code and part used.
