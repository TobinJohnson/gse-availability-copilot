# Air-conditioning unit fault
Applies to: ACU-COMP, ACU-HOSE
Example procedure for this demo. Always follow the OEM manual and station safety rules.

## Safety
Isolate electrical power and lock out before opening the compressor panel. Refrigerant work is only for certified technicians.

## Diagnosis
If the compressor does not engage, test the compressor relay and its control signal. If airflow is weak or noisy, inspect the supply duct hose for tears.

## Repair
Replace the compressor relay (P-RLY-ACU) or the supply duct hose (P-DUCT-ACU).

## Test before release
Run 15 minutes and measure outlet air temperature. Record the failure code and part used.
